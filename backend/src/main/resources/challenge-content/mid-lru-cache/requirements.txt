Implement a fixed-capacity least-recently-used cache with get, put and size.
get returns the cached value or null for a missing key, and marks the entry as most recently used.
put inserts or updates an entry and marks it as most recently used, evicting the least recently used entry when the cache is full.
size reports the number of live entries; constructing with a non-positive capacity throws IllegalArgumentException.
Updating an existing key must not change the size, and it makes that key the most recently used entry.
